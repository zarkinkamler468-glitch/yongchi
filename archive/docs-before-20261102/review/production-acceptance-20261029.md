| P1 | 生产依赖扫描报告 1 项 high、0 critical | brace-expansion 的两个安装节点受影响，本地依赖树版本为 1.1.18 和 2.1.4，路径经 ExcelJS → archiver → glob/minimatch 等。扫描报告有修复版本。风险为特制括号展开输入触发拒绝服务；本轮未证明线上业务路径可被远程利用。应修复锁文件、重新安装、审计、回归测试后再部署。不要直接执行强制大版本升级。 |

## 范围与限制

- 业务写入只发生在临时空库，正式业务数据未被测试增删改。正式数据库仅用于一致性备份和只读检查。
- 本轮属于自动化 API 验证，不等于前台人员已经完成逐页界面和操作习惯验收；登录验证码的人工交互也未在本轮代为完成。
- 500 次查询为同机隔离环境、少量数据、短时负载，不能据此承诺公网吞吐、大数据量表现或长期并发容量。
- 未实际重启正式容器、Docker 服务或主机；未执行磁盘满、断电和网络分区演练。
- 未发送实际短信，未验证微信服务、云安全组或备案信息；这些取决于后续正式配置及相应服务可用性。
- npm audit 是依赖公告扫描，不是对所有业务代码和服务器组件的完整安全审计。未执行自动修复。
- 在线备份保留在同一台服务器上，无法抵御整机或整盘丢失，不替代异机备份。
