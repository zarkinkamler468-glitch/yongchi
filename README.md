# 峡谷管理系统（纯会员制后台版 v0.5）

面向单一游泳馆内部管理人员的 Web 管理系统，覆盖会员档案、卡项与会员卡账户、办卡续费、入场核销、收银对账、退款审批、交班日结和经营报表。**仅会员制，不面向会员开放登录端**，不含散客票、课程、商品零售、多门店、会员端小程序。

- 后端：Node.js 内置 `http` + 内置 `node:sqlite`（**零第三方依赖**，`node server.js` 即跑）
- 前端：无构建单页应用（HTML/CSS/JS，毛玻璃风格）
- 数据库：SQLite（表结构对齐开发文档第 11 节，可平移到 MySQL/PostgreSQL）

## 角色与权限

| 角色 | 说明 | 主要权限 |
| --- | --- | --- |
| 老板 `boss` | 经营者 | 全部报表、员工账号、卡项/价格/有效期规则、退款审批、全部订单/交班/日结、导出、系统设置 |
| 前台 `frontdesk` | 接待收银 | 会员建档查询、办卡/续费/充值、入场核销、查看本人班次流水、发起退款、交班对账 |
| 财务 `finance` | 对账核算 | 收银流水、审核退款、交班记录、执行日结、导出报表、支付方式明细 |

默认账号：`boss / admin123`、`frontdesk / front123`、`finance / finance123`（登录后请修改）。

## 运行

```bash
cd pool-management-system
node server.js     # 或 npm.cmd start
```

浏览器访问 **http://localhost:3000**。自定义端口：`$env:PORT=3001; node server.js`。

## 业务规则要点

- 手机号唯一，儿童会员通过家庭关系关联家长；黑名单禁止办卡、续费、入场。
- 次卡每次扣 1 次（带朋友按人头扣次）；月卡按全局配置（自然月/购买日起算）；年卡默认 365 天；储值卡扣单次入场费。
- 同一会员同一天可多次入场；冻结/作废/退款卡不可入场。
- 储值余额不可提现，只能走退款流程；退款必须关联原订单，保留审批人、原因、时间。
- 混合支付：各支付方式合计必须等于实付金额；储值支付同步扣减余额。
- 所有金额保留两位小数；收银、核销、退款、冻结、转卡、作废等操作均写操作日志。

## 重置数据

停止服务后删除数据库文件即可，重新启动自动建表并写入演示数据与默认账号：

```powershell
Remove-Item data\pool.db* -Force   # Windows PowerShell
# rm -rf data/pool.db*             # macOS / Linux
```

## 说明

- 数据存本地 SQLite，适合单店/局域网；`HOST=0.0.0.0` 默认局域网可访问。
- **安全加固**：登录爆破防护（连错 5 次锁 10 分钟）、目录穿越防护、参数化 SQL 防注入、操作日志最小化（90 天自动清理）。
- **员工微信登录**：小程序内微信一键登录，首次绑定账号后免密；需在「系统设置」填入小程序 AppID/AppSecret。
- **员工端小程序**（`miniprogram/`）已适配 v0.5：登录（微信+密码）、概览、收银、会员、会员详情、入场核销、交班、统计、流水、退款审批、我的。
- **部署**：详见 [`DEPLOYMENT.md`](DEPLOYMENT.md)（Ubuntu 22.04 + 1Panel + PM2 + HTTPS + 备份 + 小程序发布）。
- 预留扩展：卡种升级、短信通知（文档 7.4 提到腾讯云短信）、二维码凭证、PDF 报表。
